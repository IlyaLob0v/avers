# История изменений

Здесь записано, что менялось в «Аверсе» для сотрудников и администратора. Новые записи добавляются сверху,
в раздел «Готовится», вместе с pull request, который вносит изменение. Номера в скобках — pull request
на GitHub.

## Готовится

- Поиск адреса подсказывает улицы и дома по мере ввода; Enter выбирает подсказку перед поиском.
- Журнал заявок сохраняет даты при русских и английских региональных настройках Windows.
- Заявки открываются из общего журнала в отдельную карточку. Приём расположен сверху: адрес,
  подъезд, квартира, описание, телефон и ответственный; пустое описание не заменяется служебной фразой.
  Изменённые карточки и новые заявки защищены от случайного ухода.
- В договоре доступны сканы PDF/JPG/PNG с отдельными правами доступа к договорным и судебным файлам.
  Платежи по единым квитанциям названы «Платежи ОЭК», добавлен порядок работы.
- В домофонах показаны понятное пустое состояние, открытые и все заявки; правки панели защищены.
  В ППР пояснён отбор по организации или зоне, калькулятор должников запрашивает дату события.
- Радиомеханик видит открытые заявки выбранного дома: квартиру, неисправность и ответственного,
  без контактов и расчётов абонента. Расчётный комплект должника включает PDF и сканы договора в ZIP;
  для юрлица выводятся реквизиты и исключаются неподходящие формы физлица.

- Рабочее окно открывается развёрнутым в доступной области экрана: нижняя строка и версия видны
  над панелью задач Windows, в том числе на экранах небольшой высоты.

- Разделы собраны в верхнем меню по рабочим задачам. «Дома» сначала показывает реестр с поиском,
  «Абоненты» — поиск без автоматически выбранной квартиры. Единственное совпадение открывается сразу,
  несколько совпадений требуют выбора по ФИО, адресу и счёту.
- Кнопка «Дом абонента» открывает связанный паспорт в пределах прав роли. Возврат восстанавливает
  выбранного абонента, дом и параметры поиска. После неудачного поиска прежняя карточка очищается,
  поэтому её нельзя случайно использовать для внесения оплаты.
- Общие настройки подтверждения оплат, подсветки, годовых начислений и изменения тарифов перенесены
  из индивидуальной карточки в отдельный блок раздела «Абоненты и оплаты».
- Уход и закрытие окна с правками дома или договора предлагают сохранить их, отменить изменения
  или остаться. Ошибка сохранения оставляет правки на экране. Поля без операции сохранения доступны
  для чтения; редактирование паспорта учитывает действующие права роли.
- Задержанный ответ поиска или перехода не возвращает данные прежнего пользователя после выхода
  и не меняет карточку в другом разделе.

- На карте при увеличении видны номера домов городского справочника; по нажатию открывается полный адрес. Импорт учитывает отдельные адресные точки и составные контуры зданий с дворами, сохраняя офлайн-доступ.

- Защищены оплаты и расторжение договора при одновременной работе сотрудников: конфликт не стирает новую оплату и не удаляет оплаченный месяц. Отмена проверяет версию выбранной оплаты.
- Сохранение паспорта и обслуживающей организации проверяет версию сведений. При конфликте программа просит обновить карточку, сохраняя изменения коллеги.
- Сохранение и удаление домов и организаций в «Словаре» также учитывает версию записи; запоздалый ответ входа на телефоне не заменяет новый сеанс.
- Юрист получает справочник адресов без технических полей, ключей, схем и графиков ППР. Сервер ограничивает состав ответа по правам роли.
- Повреждённые и пустые файлы отклоняются с понятным сообщением. Размер изображения ограничен до распаковки; суммы и тарифы проверяются на допустимый диапазон базы.
- На странице телефона поздний ответ не смешивает карточки разных домов и не открывает схему после выхода из системы.
- Если сервер недоступен при входе с телефона, страница показывает сообщение о связи и позволяет повторить вход.
- Удаление дома или улицы не стирает записи, которые другой сотрудник добавил после проверки. Ограничения базы и защита существующего SQLite отклоняют такое удаление.
- Повторная загрузка уже обработанного файла ОЭК не блокирует кассу лишними обновлениями абонентов.

- Убрана верхняя кнопка «Поиск» на карте. Раздел «Дома Аверса» сразу показывает дома из базы; строка над списком фильтрует их по улице и номеру, очистка возвращает весь список.

- Кнопка «Поиск» в верхней панели карты переводит курсор в строку адреса, сохраняя карту. Список домов Аверса открывается отдельной кнопкой «Дома».

- На рабочем столе появилась карточка «Карта Омска», установленная версия видна в строке состояния. Карта открывается с номером выпуска и перепроверяет свою страницу и скрипт после обновления; в поиске показано число доступных адресов города.

- Поиск на карте охватывает адресный слой города, включая здания вне базы Аверса. Поддерживаются части названий, «ё/е», буквы, дроби и корпуса в номере; выбранный результат перемещает карту к зданию.
- В карточке адреса убрана отдельная надпись об источнике; общая подпись карты сохранена. Поиск показывает загрузку справочника и поясняет ограничение списка результатов.

- Архив JACK открывается при русских и английских региональных настройках Windows: форматированные даты и суммы не записываются обратно в исходные строки.

- Полный набор проверок Windows запускается по проектам последовательно, с подробным журналом результатов.

- История загружается только для выбранного абонента. При открытии большого дома программа не получает
  платежи и квитанции всех квартир сразу; во время загрузки показан индикатор.
- Должники отбираются на сервере и показываются страницами по 100. Excel и массовые уведомления
  включают весь отбор, независимо от открытой страницы.
- В карточке появился архив исходных операций JACK с годом, датой поступления, источником и суммой без пересчёта.
- Отчёт для 1С группируется в базе; импорт ОЭК не выбирает произвольного абонента при повторяющемся счёте.
- Перенос не принимается без бухгалтерской сверки. Проверяется начисление каждого абонента за каждый месяц.
- Должники используют годовые итоги PostgreSQL, обновляемые вместе с оплатами; устаревший запрос отбора отменяется.
- История заявок по домофону загружается при открытии выбранного дома, а не целиком при входе.
- Перед пересозданием автономной учебной базы сохраняется копия, включая данные из журнала SQLite.
- Поиск распознаёт телефоны с точками и добавочными номерами; для телефонов и фамилий добавлены поисковые индексы.

- Нажатие на здание показывает полный адрес из локального слоя OpenStreetMap, включая дома вне базы Аверса.

- Единая версия 2.0.0 для сервера и рабочего места. На учебном входе все пользователи видны списком,
  рядом показаны задачи выбранной роли и подсказка пароля.
- Исправлены наложения в небольшом окне, переключение журналов и открытие найденной заявки вне периода.
- Появились плавные состояния кнопок и компактный индикатор запуска.

- Касса фиксирует лицевой счёт, месяц и сумму до отправки. Повтор после потери ответа возвращает результат той
  же оплаты. При нескольких совпадениях поиска сотрудник сам выбирает карточку.
- При переносе сохраняются исходные платежи JACK и проверяется каждая операция. На экране остаются месячные итоги.
- Просмотр списков и карточек заявок записывается в журнал. Поиск домов доступен при сбое карты.
- Учебный режим рабочего места использует отдельную папку `Avers/Demo`. Прежняя локальная база сохраняется.

### Добавлено
- Офлайн-карта Омска для диспетчеров, курьеров и радиомехаников: работает без интернета, карта лежит на сервере
  Аверса. Поиск дома по адресу, дома Аверса точками на карте (с неустранённой неисправностью — красные),
  из точки — сведения о доме. В программе кнопка «Карта» открывает карту в браузере на выбранном доме или доме
  заявки; на телефоне — кнопка «Карта» на странице механика. Карту скачивает администратор командой
  `sudo avers-map`, она же ставит дома на карту по адресам; остальные дома главный инженер ставит вручную.
  Учебную базу сервера (`avers-server-demo.db`) после обновления удалите: в ней нет полей для точек домов.
- Срок по заявке АДС — 3 дня от приёма. Просроченные заявки выделены в журнале красным, в карточке заявки виден
  срок, отбор «Только просроченные» оставляет их одних.
- Список заявок для ОЭК за выбранный день выгружается в Excel; если за день выполнены не все заявки, список
  не выводится.
- Отбор должников: долг от суммы, неоплачено от числа месяцев, улица и дом, есть ли судебный приказ. Отчёт
  по должникам и претензии формируются по отобранным.
- Клиент — физическое или юридическое лицо (контрагент). В карточке квартиры отметка «Юридическое лицо»
  и реквизиты: ИНН, КПП, ОГРН, юридический адрес, руководитель. В списке должников столбец «Клиент» и отбор
  по нему. Льгота «юридическое лицо» убрана: у кого она стояла, те стали юрлицами; при переносе из старого Аверса
  так же становятся юрлицами абоненты с этой льготой.
  Рабочие места нужно обновить: старая версия не сможет сохранить карточку.
- Поиск абонента по телефону: номер звонящего в любой записи (+7, 8, скобки, дефисы) или его последние цифры.
- Перенос данных из старого Аверса: улицы, дома, домовладельцы, механики, абоненты с договорами и лицевыми счетами
  ПЖРЭУ, начисления и оплаты с 1998 года, квитанции ПЖРЭУ, заявки и ППР. После переноса сверка сравнивает старую
  и новую базу: число записей, суммы начислений и оплат по каждому месяцу, долг каждого абонента. План дня
  переезда — [docs/12-cutover-plan.md](docs/12-cutover-plan.md).

### Изменено
- Сотрудники подключаются к серверу по защищённому соединению (HTTPS); первая установка не включает учебные
  данные; копии базы делаются по расписанию и раз в неделю проверяются пробным восстановлением (#107).
- Итоги месяца для 1С видят только администратор и начальник АДС (#108).
- Читатель и юрист больше не получают с сервера список радиомехаников с телефонами, материалы и заявки
  по домофонам (#108).
- Схему «только на экране» и схему на телефоне сервер отдаёт картинкой с водяным знаком, исходный файл
  получает только тот, кому схемы открыты на просмотр (#108).
- Заявки больше не загружаются целиком при входе: журнал, сводка по месяцам и отчёты запрашивают у сервера
  только нужное. Вход и запись заявки не замедляются с ростом истории. Нужна новая версия программы на всех
  рабочих местах: старая получит «Обновите программу».
- Автотесты проверяют работу рабочего места через сервер для денежных операций: ввод и отмена оплаты, долги,
  итоги месяца для 1С, смена тарифа, договор и реквизиты юрлица, судебное дело, загрузка файла ОЭК, отказ
  без прав и нет связи с сервером. Тесты переноса из старого Аверса без PostgreSQL отмечаются пропущенными.

### Исправлено
- Загрузка файла ОЭК не затирает оплату, которую кассир внёс во время загрузки (#105).
- Любой адрес сервера без отдельного правила доступа требует входа (#108).
- Описание API для разработчика (`/openapi/v1.json`) снова открывается.
- Журнал изменений при быстром переключении на журнал просмотров (и обратно) показывает записи выбранного журнала.

### Документация
- Инструкция по серверу переписана под HTTPS в офисе: корневой сертификат на рабочие места, адрес `https://`,
  переход со старого адреса `http://…:5115`, настройка копий через `/etc/avers-backup.env`, проверка
  восстановления и восстановление сервера «с нуля».
- Руководство пользователя по должностям, инструкция по запуску для знакомства, руководство разработчика
  и эта история изменений.
