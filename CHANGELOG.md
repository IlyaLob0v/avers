# История изменений

Здесь записано, что менялось в «Аверсе» для сотрудников и администратора. Новые записи добавляются сверху,
в раздел «Готовится», вместе с pull request, который вносит изменение. Номера в скобках — pull request
на GitHub.

## Готовится

### Изменено
- Сотрудники подключаются к серверу по защищённому соединению (HTTPS); первая установка не включает учебные
  данные; копии базы делаются по расписанию и раз в неделю проверяются пробным восстановлением (#107).
- Итоги месяца для 1С видят только администратор и начальник АДС (#108).
- Читатель и юрист больше не получают с сервера список радиомехаников с телефонами, материалы и заявки
  по домофонам (#108).
- Схему «только на экране» и схему на телефоне сервер отдаёт картинкой с водяным знаком, исходный файл
  получает только тот, кому схемы открыты на просмотр (#108).

### Исправлено
- Загрузка файла ОЭК не затирает оплату, которую кассир внёс во время загрузки (#105).
- Любой адрес сервера без отдельного правила доступа требует входа (#108).
- Описание API для разработчика (`/openapi/v1.json`) снова открывается.
- Журнал изменений при быстром переключении на журнал просмотров (и обратно) показывает записи выбранного журнала.

### Документация
- Инструкция по серверу переписана под HTTPS в офисе: корневой сертификат на рабочие места, адрес `https://`,
  переход со старого адреса `http://…:5115`, настройка копий через `/etc/avers-backup.env`, проверка
  восстановления и восстановление сервера «с нуля».
- Руководство пользователя по должностям, инструкция по запуску для знакомства, руководство разработчика
  и эта история изменений.

### Исправлено

- Расторжение договора останавливает начисления (#65).
- Отключение сотрудника и смена роли действуют сразу (#51).
- Суммы и даты в файле ОЭК, записанные текстом, читаются верно (#84); права на окна совпадают с правами
  на кнопки модулей (#85).
