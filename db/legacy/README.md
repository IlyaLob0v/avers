# db/legacy — инвентаризация старой базы (Oracle, схема JACK)

Запросы только на чтение. Запускает администратор Oracle (SQL*Plus, SQL Developer) под пользователем с правом
чтения словаря. Результаты сохранить в CSV и передать в файлы проекта. **Данные абонентов не выгружать** — только структура и объёмы.

- `01-inventory.sql` — версия, кодировка, объекты, таблицы, столбцы, ключи, объёмы
- `02-plsql-source.sql` — исходный код процедур, функций, пакетов, триггеров, представлений

Папки `dumps/` и `data/` игнорируются git: туда кладутся выгрузки с персональными данными только на стенде.
