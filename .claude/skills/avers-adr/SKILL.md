# Новый ADR

Общая методика выбора — скилл `engineering:architecture`. Здесь — правила оформления в этом репозитории.

1. Номер: следующий после последнего файла `docs/adr/NNNN-*.md`. Имя файла — `NNNN-кратко-латиницей.md`.
2. Скопируй `docs/adr/0000-template.md`, заполни все разделы по-русски:
   - Статус — «Предложено». «Принято» ставит только пользователь.
   - Дата — сегодняшняя, `ГГГГ-ММ-ДД`.
   - Варианты — минимум два, с плюсами и минусами для условий Аверса (Windows 7/10 на рабочих местах,
     Oracle 10.2 в источнике, 1С 8.3, маленькая команда).
   - Версии, сроки поддержки и лицензии проверь в интернете или через Microsoft Learn в момент записи,
     ссылки — в раздел «Источники».
3. Если решение заменяет прежнее — в старом ADR поменяй статус на «Заменено ADR-NNNN», текст не переписывай.
4. Обнови ссылки: `docs/03-architecture.md` (если меняется схема), при новом разделе — `docs/00-index.md`.
5. Открытые вопросы, без ответа на которые решение не принять, — в `docs/07-open-questions.md`
   (скилл `avers-open-question`), а в ADR сошлись на их номер.
