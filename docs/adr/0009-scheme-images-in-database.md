# ADR-0009. Картинки схем СКПТ хранятся в PostgreSQL

- Статус: Принято
- Дата: 2026-10-19
- Участники: Илья

## Контекст
Радиомеханик должен видеть схему СКПТ с телефона (REQ-MECH-01), без возможности скачать файл (REQ-MECH-02).
В архитектуре было отдельное хранилище файлов. Схем — сотни, каждая — одна картинка до нескольких мегабайт.
Сервер один, база одна, ночной резервный pg_dump уже настроен.

## Варианты
1. Папка на сервере. Плюс — база меньше. Минус — отдельное резервное копирование и права на папку, файлы и записи о них могут разойтись.
2. Таблица в PostgreSQL (`HouseSchemeFiles`, bytea). Плюс — попадает в ночной бэкап, правится в одной транзакции с журналом изменений. Минус — база растёт на объём картинок.

## Решение
Вариант 2. Картинка — JPG или PNG до 10 МБ, формат проверяется по первым байтам файла. Картинка лежит в отдельной
таблице, чтобы снимок данных для настольной программы и карточка дома на телефоне не тянули файлы.
Отдаётся только вошедшему пользователю: `/api/schemes/{id}/file` (модуль «Схема СКПТ») и `/api/mobile/schemes/{id}` (телефон).
На телефоне картинка рисуется на холсте с водяным знаком «Аверс · логин · дата».

## Последствия
- Резервная копия растёт на объём схем; при сотнях схем по 1–3 МБ это сотни мегабайт.
- PDF и SVG не принимаются. Если схемы на предприятии в PDF, их нужно сохранить картинкой или добавить PDF отдельно.
- Скриншот экрана телефона водяной знак не запрещает, только помечает.
