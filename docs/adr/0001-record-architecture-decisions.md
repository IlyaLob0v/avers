# ADR-0001. Фиксировать архитектурные решения в ADR

- Статус: Принято
- Дата: 2026-10-14

## Контекст
Проект длинный, участников несколько (люди и агенты Claude), а предыдущая оболочка выбрала MS SQL Server
без записанного обоснования. Нужна память решений.

## Решение
Каждое значимое решение — файл `docs/adr/NNNN-название.md` по шаблону `0000-template.md`.
Решение не удаляем: отменённое помечаем «Заменено ADR-XXXX».

## Последствия
Агент `architect` пишет ADR; оркестратор требует ADR при выборе технологий.
