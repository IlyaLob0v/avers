# ADR-0003. Клиент-сервер: сервер приложений, настольный клиент и веб-интерфейс

- Статус: Предложено
- Дата: 2026-10-14

## Контекст
Оболочка — «толстый» клиент с прямым доступом к локальной SQLite. Требования, которые так не закрыть:
просмотр с телефона радиомехаников (REQ-MECH-01/02), обмен с 1С, автоматический импорт реестров, жёсткие права,
рабочие места на Windows 7 (на них .NET 10 не работает).

## Варианты
1. **Толстый клиент → общая БД** (как в старом Аверсе). Просто, но права и логика на клиенте, пароль к БД на каждом ПК,
   телефон и Win7 не решены.
2. **Только веб** (Blazor/SPA). Работает везде, включая Win7 и телефон. Минус — потеря привычной «настольной» плотности
   и скорости ввода, оболочку на Avalonia придётся выбросить.
3. **Сервер приложений + Avalonia-клиент + веб-интерфейс.** Логика и права на сервере; Avalonia остаётся на основных
   рабочих местах (Win10/11); веб-интерфейс для телефона (только чтение) и, при необходимости, для Win7.

## Решение
Вариант 3. Веб-интерфейс начинаем с режима Читателя (дом, техника, схема), расширяем по необходимости.
Машины с Windows 7: в приоритете — обновление до Windows 10/11; до этого — RemoteApp на терминальном сервере (ADR-0008).

## Последствия
- Экраны оболочки переходят с прямого доступа к БД на вызовы API (`Avers.Contracts`).
- Нужен сервер в сети предприятия и способ доступа с телефонов: VPN (предпочтительно) или публикация через обратный прокси с HTTPS.
- Учебный режим оболочки (SQLite) сохраняем для демонстраций.
