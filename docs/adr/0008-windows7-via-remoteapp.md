# ADR-0008. Windows 7: Аверс через удалённый рабочий стол (RemoteApp)

- Статус: Принято
- Дата: 2026-10-15
- Участники: Илья

## Контекст
У многих сотрудников Windows 7. .NET 10 (ADR-0004) на ней не запускается, .NET 8 тоже: последняя версия .NET
с поддержкой Windows 7 — .NET 6, её поддержка закончилась 12.11.2024. У предприятия есть свой сервер.

## Варианты
1. **Отдельная сборка под старую платформу** — две версии программы, платформа без обновлений безопасности.
2. **Веб-интерфейс для Windows 7** (ADR-0003) — всё равно нужен, но полный набор экранов в вебе появится нескоро.
3. **Терминальный сервер (RDS) + RemoteApp.** Программа ставится на Windows Server, сотрудник с Windows 7
   открывает её ярлыком; окно выглядит как обычная программа, а работает на сервере.

## Решение
Вариант 3: одна сборка для всех. На Windows 10/11 Аверс ставится как обычно, на Windows 7 открывается через RemoteApp.
Инструкция для администратора — [08-terminal-server.md](../08-terminal-server.md).

## Последствия
- Нужны лицензии Windows Server и RDS CAL (см. инструкцию).
- Программа обязана корректно работать, когда её одновременно запускают несколько сотрудников на одном сервере:
  данные — только в профиле пользователя (`%LOCALAPPDATA%\Avers`), рядом с программой ничего не пишем,
  подготовка учебной базы защищена блокировкой от второго экземпляра, в RDP-сеансе отрисовка программная.
- Общие данные у сотрудников появятся, когда клиент перейдёт на сервер приложений (ADR-0003);
  до этого у каждого сотрудника на сервере своя учебная база, как и на отдельном компьютере.
