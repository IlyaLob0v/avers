# ADR-0017. Офлайн-карта города на сервере Аверса

- Статус: Предложено
- Дата: 2026-11-11
- Участники: Илья

## Контекст
В одном из отделов нет интернета. Раньше там пользовались офлайн-версией 2ГИС для компьютера, её больше
не обновляют. Диспетчерам и курьерам нужна карта города, на которой видны дома Аверса, без интернета.
Рабочие места подключены к серверу Аверса по офисной сети; сотрудники с Windows 7 работают через xrdp на сервере.

## Варианты
1. Оставить 2ГИС для ПК. Плюс — ничего делать не нужно. Минус — данные не обновляются, наших домов и заявок там нет.
2. Карта внутри настольной программы (элемент карты для Avalonia). Минус — готовые элементы (Mapsui) рассчитаны
   на Avalonia 11; растровые плитки для них пришлось бы рисовать отдельной программой.
3. Карта в браузере, данные с сервера Аверса. Подложка — один файл PMTiles с векторной картой OpenStreetMap
   (вырезка Омска из ежедневной сборки Protomaps), рисует MapLibre GL JS. Библиотеки и шрифты лежат на сервере.

## Решение
Вариант 3. Карта — раздел страницы `/m/`: на телефоне и на компьютере одна и та же страница. В программе кнопка
«Карта» открывает её в браузере на выбранном доме. Файл карты отдаётся по частям только вошедшему сотруднику
(`/api/mobile/map/tiles`), право — просмотр раздела «Дома и антенны». Точки домов хранятся в базе (`Houses.Latitude`,
`Houses.Longitude`): их ставит по адресам OpenStreetMap команда `avers-map`, остальные главный инженер или
администратор ставят на карте вручную.

## Последствия
- Карту нужно скачать один раз на компьютере или сервере с интернетом и потом обновлять по желанию (раз в год хватит).
  Файл Омска — десятки мегабайт.
- Нужен браузер с WebGL 2: Chrome, Edge, Firefox последних лет. Через xrdp карта рисуется процессором, медленнее.
- Справочника организаций, как в 2ГИС, нет: только улицы, дома, подписи OpenStreetMap и наши дома.
- Данные OpenStreetMap — лицензия ODbL, подпись «© участники OpenStreetMap» на карте обязательна.
- Браузер просит войти отдельно от программы: передавать токен в строке запуска браузера небезопасно.
