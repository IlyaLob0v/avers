# ADR-0007. Отчёты в XLSX и PDF вместо XPS

- Статус: Предложено
- Дата: 2026-10-14

## Контекст
Старая система выдаёт отчёты в XPS, сотрудники просят удобный формат и выбор метрик (REQ-ENG-08, REQ-LAW-04, REQ-ACC-*).
Нужны печатные формы: лицевой счёт, квитанция, претензия, справка о задолженности, реестр договоров.

## Варианты
- XLSX: **ClosedXML** (MIT) — простой API; EPPlus — платный для коммерции с версии 5.
- PDF: **QuestPDF** — удобный код, но Community-лицензия бесплатна только для компаний с годовой выручкой до 1 млн USD
  (проверить; по сверке августа выручка около 5,7 млн ₽/мес — порог не превышен, но решение за юристом/руководством);
  **PDFsharp + MigraDoc** (MIT) — без ограничений, API беднее.
- Генератор отчётов (FastReport Open Source) — дизайнер шаблонов, но сложнее встраивать.

## Решение
XLSX — ClosedXML. PDF — QuestPDF при подтверждении лицензии, иначе PDFsharp/MigraDoc. Отчёты строятся на сервере.
Конструктор отчётов — набор метрик в справочнике + выбор колонок пользователем.

## Последствия
Лицензию QuestPDF проверить перед первым PDF-отчётом.
