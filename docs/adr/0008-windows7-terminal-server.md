# ADR-0008. Windows 7: Аверс через терминальный сервер Linux (xrdp)

- Статус: Принято
- Дата: 2026-10-16 (вариант с Windows Server предложен 2026-10-15)
- Участники: Илья

## Контекст
У многих сотрудников Windows 7. .NET 10 (ADR-0004) на ней не запускается, .NET 8 тоже: последняя версия .NET
с поддержкой Windows 7 — .NET 6, её поддержка закончилась 12.11.2024. У предприятия есть свой сервер.
Microsoft с 2022 года не продаёт лицензии в России напрямую.

## Варианты
1. **Отдельная сборка под старую платформу** — две версии программы, устаревшие библиотеки.
2. **Веб-интерфейс для Windows 7** (ADR-0003) — нужен механикам, но полный набор экранов в вебе появится нескоро.
3. **Windows Server + RemoteApp.** Окно Аверса неотличимо от обычной программы, печать на принтер сотрудника.
   Нужны лицензии Windows Server, Windows Server CAL и RDS CAL — в России только через посредников.
4. **Linux + xrdp.** Аверс (Avalonia) работает на Linux без изменений. Бесплатно, клиент — стандартное
   «Подключение к удалённому рабочему столу». Минусы: Аверс открывается во весь экран удалённого сеанса,
   печать на принтер сотрудника хуже, нужен администратор Linux.

## Решение
Вариант 4 (выбрал Илья 16.10.2026). Одна сборка Аверса для всех; на Windows 10/11 он ставится напрямую,
на Windows 7 открывается с сервера Linux. Вариант 3 описан как запасной.
Инструкции: [08-terminal-server.md](../08-terminal-server.md), [08б](../08-terminal-server-windows.md).

## Последствия
- Программа обязана корректно работать, когда её одновременно запускают несколько сотрудников на одном сервере:
  данные — только в профиле пользователя, рядом с программой ничего не пишем, подготовка учебной базы
  защищена блокировкой от второго экземпляра.
- CI собирает `Avers-linux-x64` (программа + `deploy/xrdp`) и проверяет запуск.
- Печать (когда появится) — на сетевой принтер сервера или в PDF.
- Общие данные у сотрудников появятся, когда клиент перейдёт на сервер приложений (ADR-0003);
  до этого у каждого сотрудника на сервере своя учебная база.
