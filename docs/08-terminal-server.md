# 08. Аверс на терминальном сервере (для Windows 7)

Программа ставится один раз на Windows Server. Сотрудник с Windows 7 щёлкает ярлык «Аверс» на своём рабочем столе,
и открывается обычное окно Аверса, которое на самом деле работает на сервере (RemoteApp). Решение — ADR-0008.

> Сейчас Аверс работает на учебной базе: у каждого сотрудника на сервере своя копия, общих данных пока нет.
> Общие данные появятся, когда программа перейдёт на сервер приложений. Сервер RDS для этого менять не придётся.

## 1. Что нужно

| Что | Какое | Зачем |
|---|---|---|
| Сервер | **Windows Server 2022 Standard** (подойдёт и 2025) | На нём работает Аверс. .NET отдельно ставить не нужно, он внутри сборки |
| Железо (оценка, уточнить на пилоте) | 4 ядра, 16 ГБ памяти, SSD; на каждые 10 одновременных сотрудников ещё ~2 ГБ | Каждый сотрудник — отдельный запуск программы |
| Лицензия Windows Server | Standard, по ядрам (минимум 16 ядер на сервер) | Обычная лицензия на сервер |
| Windows Server CAL | По одной на каждого сотрудника или каждый компьютер | Право подключаться к серверу |
| **RDS CAL** | По одной на каждого сотрудника (**Per User**) или на каждый компьютер (**Per Device**) | Право работать через удалённый рабочий стол |

Как выбрать тип RDS CAL:
- сервер **в домене** — можно любой; Per User выгоднее, если у каждого свой компьютер;
- сервер **без домена** (рабочая группа) — только **Per Device**;
- если за одним компьютером работают посменно несколько человек — Per Device.

Версия RDS CAL должна быть не старше сервера: на Windows Server 2022 подходят CAL 2022 и 2025, на 2025 — только 2025.
Первые **120 дней** сервер работает без лицензий — этого хватит на пилот.

## 2. Установка программы на сервер

1. Скачайте сборку `Avers-win-x64.zip` (GitHub → вкладка **Actions** → последний зелёный запуск **CI** → внизу раздел
   **Artifacts** → **Avers-win-x64**).
2. Распакуйте. Папку `Avers` скопируйте в `C:\Program Files\` — получится `C:\Program Files\Avers\Avers.exe`.
3. Проверьте: зайдите на сервер под обычной учётной записью сотрудника и дважды щёлкните `Avers.exe`.
   Должно открыться окно входа.

Программа ничего не пишет в свою папку: база и настройки каждого сотрудника лежат в его профиле
(`C:\Users\<имя>\AppData\Local\Avers`). Обновление — закрыть Аверс у всех и заменить папку `C:\Program Files\Avers`.

## 3. Публикация как RemoteApp

Выберите вариант по тому, есть ли в организации домен.

### Вариант А. Сервер в домене (рекомендуется)

1. **Диспетчер серверов** → **Управление** → **Добавить роли и компоненты**.
2. Тип установки: **Установка служб удалённых рабочих столов** → **Быстрый запуск** → **Развёртывание рабочих столов
   на основе сеансов** → выберите этот сервер → поставьте галочку **Автоматически перезапускать** → **Развернуть**.
3. После перезагрузки: **Диспетчер серверов** → **Службы удалённых рабочих столов** → **Коллекции** →
   **QuickSessionCollection** → в блоке **Программы RemoteApp** → **Задачи** → **Опубликовать программы RemoteApp**.
4. Нажмите **Добавить** → укажите `C:\Program Files\Avers\Avers.exe` → **Далее** → **Опубликовать**.
5. Лицензии: **Службы удалённых рабочих столов** → **Обзор** → **Задачи** → **Изменить свойства развёртывания** →
   **Лицензирование удалённых рабочих столов** → выберите **На пользователя** или **На устройство** → укажите этот сервер.
   Затем **Пуск** → **Средства администрирования** → **Диспетчер лицензирования удалённых рабочих столов** →
   правой кнопкой по серверу → **Активировать сервер**, потом **Установить лицензии**.
6. Ярлык для сотрудников: на компьютере администратора откройте в браузере `https://<сервер>/RDWeb`, войдите,
   щёлкните **Аверс** — скачается файл `.rdp`. Этот файл и раздайте сотрудникам (см. раздел 4).

### Вариант Б. Сервер без домена

1. **Диспетчер серверов** → **Управление** → **Добавить роли и компоненты** → **Установка ролей или компонентов** →
   роль **Службы удалённых рабочих столов** → службы ролей **Узел сеансов удалённых рабочих столов** и
   **Лицензирование удалённых рабочих столов** → **Установить**, затем перезагрузка.
2. Лицензии: **Диспетчер лицензирования удалённых рабочих столов** → активировать сервер и установить RDS CAL
   **на устройство**. Затем **Пуск** → `gpedit.msc` → **Конфигурация компьютера** → **Административные шаблоны** →
   **Компоненты Windows** → **Службы удалённых рабочих столов** → **Узел сеансов удалённых рабочих столов** →
   **Лицензирование**: «Использовать указанные серверы лицензирования» — имя этого сервера,
   «Задать режим лицензирования» — **На устройство**.
3. Разрешите Аверс как RemoteApp: дважды щёлкните файл [`deploy/rds/avers-remoteapp.reg`](../deploy/rds/avers-remoteapp.reg)
   на сервере → **Да**.
4. Сотрудникам, которые будут работать в Аверсе, добавьте учётные записи на сервере и включите их в группу
   **Пользователи удалённого рабочего стола** (**Управление компьютером** → **Локальные пользователи и группы**).
5. Ярлык: откройте [`deploy/rds/Avers.rdp`](../deploy/rds/Avers.rdp) в Блокноте, замените `SERVER-NAME` на имя
   или адрес сервера, сохраните.

## 4. Подключение сотрудника с Windows 7

Один раз на каждом компьютере с Windows 7:

1. Проверьте версию клиента: **Пуск** → **Подключение к удалённому рабочему столу** → значок в левом верхнем углу
   окна → **О программе**. Нужна строка «Поддерживается протокол удалённого рабочего стола 8.1».
2. Если там 7.1 — установите обновления KB2574819, KB2857650, KB2830477, KB2923545 (в этом порядке) и перезагрузите.
3. Если при подключении пишет «ошибка проверки подлинности … CredSSP» — нужно накопительное обновление
   Windows 7 не старше мая 2018 (KB4103718 или новее).

Дальше:

1. Положите файл `Avers.rdp` на рабочий стол сотрудника (можно переименовать в «Аверс»).
2. Сотрудник дважды щёлкает его, вводит логин и пароль от сервера, ставит галочку **Запомнить учётные данные**.
3. Открывается Аверс. Его окно можно сворачивать и закрывать как обычную программу. Принтеры компьютера
   доступны из Аверса.

## 5. Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Удалённый компьютер требует проверки подлинности на уровне сети» | Обновления из раздела 4 не установлены |
| «Нет доступных серверов лицензирования» после 120 дней | Не активирован сервер лицензий или не установлены RDS CAL (раздел 3, шаг про лицензии) |
| Вместо Аверса открывается весь рабочий стол сервера | В варианте Б не применён `avers-remoteapp.reg` или в `.rdp` неверная строка `remoteapplicationprogram` |
| Аверс не запускается у сотрудника, у администратора работает | Проверьте, что программа лежит в `C:\Program Files\Avers`, а у сотрудника есть право чтения на эту папку (по умолчанию есть) |

Windows 7 больше не получает обновлений безопасности. Компьютеры с ней лучше не выпускать в интернет и со временем
перевести на Windows 10/11 — Аверс там ставится напрямую, без сервера.
