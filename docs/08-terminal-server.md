# 08. Аверс на сервере Linux для сотрудников с Windows 7

Аверс ставится на сервер с Linux. Сотрудник с Windows 7 открывает ярлык на рабочем столе, вводит логин и пароль,
и во весь экран открывается Аверс, который работает на сервере. Интернет не нужен, всё внутри локальной сети.
Лицензии Microsoft не нужны. Решение — ADR-0008. Запасной вариант на Windows Server — [08б](08-terminal-server-windows.md).

> Сейчас Аверс работает на учебной базе: у каждого сотрудника на сервере своя копия, общих данных пока нет.
> Общие данные появятся, когда программа перейдёт на сервер приложений. Этот сервер для этого менять не придётся.

## Как это проверено

На тестовом сервере Ubuntu 24.04 с xrdp одновременно работали два сотрудника, у каждого свой сеанс и своя база.
Вход, переход по модулям, ввод по-русски с переключением Alt+Shift, переподключение после обрыва — работают.
С настоящим компьютером на Windows 7 ещё не проверяли: начните с одного компьютера (раздел 4).

## 1. Что нужно

| Что | Какое |
|---|---|
| Сервер | **Ubuntu Server 24.04 LTS** (бесплатно). Astra Linux и РЕД ОС тоже подойдут, но скрипт установки написан для Ubuntu |
| Память | ~300 МБ на каждого одновременно работающего сотрудника + 2 ГБ системе. На 20 человек — 8 ГБ, лучше 16 ГБ |
| Процессор | 4 ядра на 20–30 сотрудников. Когда сотрудник ничего не делает, нагрузки нет |
| Диск | 20 ГБ под систему и программу |
| Сеть | Сервер и компьютеры сотрудников в одной локальной сети, порт **3389** открыт |
| Человек | Администратор, который умеет войти на сервер Linux и выполнить команду |

## 2. Установка

1. Установите на сервер Ubuntu Server 24.04 LTS (обычная установка, галочку **OpenSSH server** поставьте).
2. Скачайте сборку: GitHub → вкладка **Actions** → последний зелёный запуск **CI** → внизу **Artifacts** →
   **Avers-linux-x64**. Перенесите архив на сервер и распакуйте (`unzip Avers-linux-x64.zip -d avers`).
3. В распакованной папке выполните:
   ```
   sudo bash install.sh
   ```
   Скрипт ставит xrdp, кладёт программу в `/opt/avers` и настраивает сеанс так, что вместо рабочего стола Linux
   сразу открывается Аверс. Закрыл Аверс — сеанс завершился.
4. Заведите учётную запись каждому сотруднику: `sudo adduser ivanova` (спросит пароль).

Обновление: все закрывают Аверс, администратор распаковывает новую сборку и снова запускает `sudo bash install.sh`.
Данные сотрудников лежат в их домашних папках (`/home/<логин>/.local/share/Avers`) и при обновлении не трогаются.

## 3. Компьютер с Windows 7

Один раз на каждом компьютере:

1. Дважды щёлкните [`windows7-tls12.reg`](../deploy/xrdp/windows7-tls12.reg) (лежит рядом с `install.sh`) → **Да**,
   затем перезагрузите компьютер. Он включает защищённое соединение TLS 1.2: без него Windows 7 к серверу не подключится.
2. Откройте [`Avers.rdp`](../deploy/xrdp/Avers.rdp) в Блокноте, замените `SERVER-NAME` на имя или адрес сервера,
   сохраните и положите на рабочий стол сотрудника (можно переименовать в «Аверс»).
3. Сотрудник дважды щёлкает ярлык, вводит логин и пароль, ставит галочку **Запомнить учётные данные**.
   На вопрос о сертификате сервера — **Больше не выводить запрос** → **Да**.

Как работать:
- Русский/английский — **Alt+Shift**, как обычно.
- Свернуть Аверс — кнопка на синей полосе вверху экрана.
- Если пропала сеть, просто откройте ярлык снова: Аверс продолжит с того же места, ничего не потеряется.

## 4. Пробный запуск

Перед тем как раздавать ярлыки всем, проверьте на одном компьютере с Windows 7: подключение, вход, ввод фамилии
по-русски, работа 15–20 минут. Если что-то не так — пришлите снимок экрана с ошибкой.

## 5. Если что-то не так

| Что видно | Что сделать |
|---|---|
| «Произошла ошибка проверки подлинности» или соединение сразу рвётся | Не применён `windows7-tls12.reg` или компьютер не перезагружен |
| «Не удаётся подключиться к удалённому компьютеру» | Сервер выключен, неверный адрес в `Avers.rdp` или закрыт порт 3389 |
| После входа чёрный экран и сразу отключение | На сервере нет `/opt/avers/Avers` — повторите `sudo bash install.sh` |
| Не переключается раскладка | Подождите пару секунд после входа и нажмите Alt+Shift ещё раз |

## Чего пока нет

- **Печать на принтер сотрудника.** Печать в Аверсе ещё не сделана. Когда появится, печатать будем на сетевой
  принтер, подключённый к серверу, или сохранять PDF.
- **Excel на сервере.** Отчёты по плану выгружаются в XLSX и PDF; открывать их будем на компьютере сотрудника.

Windows 7 больше не получает обновлений безопасности. Компьютеры с ней лучше не выпускать в интернет и со временем
перевести на Windows 10/11 — Аверс там ставится напрямую, без сервера.
