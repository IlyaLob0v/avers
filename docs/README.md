## Как поддерживать документацию

Документация меняется в том же pull request, что и код. Минимум — строка в [CHANGELOG.md](../CHANGELOG.md).
Если поменялся экран или порядок работы, правится раздел [руководства пользователя](user-guide/README.md)
и, при необходимости, снимок в [images/](images/). Подробнее — в [development.md](development.md#как-вносить-изменения).
