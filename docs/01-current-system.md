# 01. Обзор текущей системы

Статус: черновик по материалам проекта на 14.10.2026. Источники — в конце каждого раздела.
Пометки: **[факт]** — проверено по файлу или коду; **[догадка]** — вывод по скриншотам/косвенным данным.

## 1. Назначение

Учёт абонентов антенной службы Омска (коллективные антенны, СКПТ, домофоны): лицевые счета и платежи за
техобслуживание отводов, приём заявок от жильцов, паспорта домов и техника, договоры, сметы, графики ППР.
Пользователи: диспетчеры АДС, начальник АДС, начальник антенной службы, главный инженер, радиомеханики,
юристы, бухгалтерия, администратор.

## 3. Данные

- СУБД: **Oracle**. Алиасы BDE `avers81` и `avers102`, пользователь `jack`, `LANGDRIVER ancyrr` (кириллица cp1251) **[факт: `bdemerge.ini`]**.
  Боевая — `avers102` на сервере `servora` **[факт по исходникам]**; `avers81` — вероятно старая база 8.1 **[догадка]**.
- На рабочих местах — клиент Oracle 9.0 (`C:\oracle\ora90\BIN`) **[факт: `ora90-path.txt`]**.
- Реальные таблицы схемы `JACK`, найденные в SQL исходников **[факт]**:
  `PHYSPERS` (физлица), `JURPERS` (юрлица), `PHYSPERS_SCORE` (лицевые счета), `BUILDING` (дома), `STREETS`,
  `CONNLIST` (отводы), `PRIVROLL` / `PRIVLONG` (льготы), `ALL_DEMANDS` (заявки), `PAY_IMPORT`, `ABN_PAY_BUFF` (буфер загрузки платежей).
- Серверная логика: процедура `JACK.IMPORTPAYFROMBUFF` переносит платежи из буфера в учёт **[факт]**. Остальные пакеты/триггеры неизвестны.
- Таблицы `CLIENTS`, `HOUSES`, `MATERIALS`, `WORKS`, `CUSTOMERS`, `MECHANICS`, `ESTIMATE_*`, `OWNERS`, `APARTMENTS`, `CONTRACTS`
  из документа «существующие решения» — **[догадка]**: восстановлены по скриншотам и для миграции не годятся.
- Отдельная база PostgreSQL `abonent` (SMS) **[факт]**.
- **Нет:** DDL схемы `JACK`, кода PL/SQL, объёмов таблиц, `NLS_CHARACTERSET`.

## 5. Инфраструктура

- Рабочие места: Windows 10 и Windows 7; есть виртуальная машина и ноутбук разработчика **[факт: память проекта]**.
- Старые формы рассчитаны на 1024×768, Windows XP, шрифт Tahoma 8 **[факт: разбор экранов]**.
- Сеть 192.168.37.0/24. Есть лицензии СУБД и сервер **[факт: ответ пользователя]**, какие именно — уточнить.

## 6. Новая оболочка (сентябрь 2026)

Avalonia 11 + .NET 8 + SQLite, три слоя (Desktop / Domain / Data), 8 ярлыков-модулей, учебная база Омска,
6 учебных ролей. Работали: вход, навигация, поиск абонента, учебные оплата и заявка, паспорт дома.
Макет: печать, XLSX/PDF, пакет в суд, «Дело-Аверс», схемы с диска, жёсткие права, перенос данных.
В октябре 2026 оболочка перенесена в репозиторий (исходный вид — ветка `import/shell-net8`) и переведена
на .NET 10 и Avalonia 12 (ADR-0004).

## 7. Главные проблемы

1. .NET 8 заканчивает поддержку 10.11.2026. Решено: оболочка уже на .NET 10 LTS (поддержка до 14.11.2028), ADR-0004.
2. Oracle 10.2 и клиент 9.0 давно без поддержки; BDE — 32-битный, снят с поддержки.
3. Логика размазана: Delphi (TQuery с SQL в формах), PL/SQL, Java. Права — скрытый режим Alt+Backspace.
4. Нет серверного слоя: телефонный доступ радиомехаников и 1С некуда подключать.
5. Отчёты в XPS; сверка ОЭК и бухгалтерские отчёты — вручную.
6. ФИО обрезается (ограничение длины полей/экранов).
7. Windows 7 на части рабочих мест: .NET 10 там не запускается.
