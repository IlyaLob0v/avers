## Этап 1. Быстрый результат для бухгалтерии

Цель — показать пользу до готовности всей системы.
- Отчёт «Отгрузка за месяц»: отводы × тариф, физлица / юрлица / ТСЖ
- Отчёт «Оплаты по источникам» в форме бумажной сверки августа
- Сверка цифр с августом 2026 вместе с бухгалтерией

Данные — из копии JACK на стенде (не с боевой базы). Результат — XLSX.

## Этап 2. Сервер и база

- Схема PostgreSQL, EF Core, сервер ASP.NET Core, аутентификация и роли
- Пробная миграция справочников, абонентов, платежей; автоматическая сверка
- Оболочка переходит с SQLite на API сервера

## Этап 3. Рабочие места АДС и инженера

- AversAbon (платежи), AversDisp (заявки, ОЭК), AversAnten (паспорт дома, схемы, ППР, неисправности)
- Печать лицевого счёта и квитанций, справочники, договоры, домофон
- Импорт банковских реестров (замена ImportPay)
- Испытания с диспетчерами и инженером, правки по протоколу

## Этап 4. 1С

- Выгрузка файлов для 1С, затем обмен через OData (ADR-0006)
- Отчёты по 62.01 / 62.02, автоматическая сверка с ОЭК

## Этап 5. Юристы и Читатель

- Связь с «Дело-Аверс» (после выяснения, что это)
