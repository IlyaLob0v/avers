# 02. Требования

Статус: черновик. Источники: `knowledge/Требования_от_сотрудников.pdf` (далее PDF), фото ТЗ бухгалтерии
(`knowledge/5359594834785672477.jpg`), сверка ОЭК (фото …478–480), список ТСЖ (фото …481).
Приоритет MoSCoW: **M** — обязательно, **S** — желательно, **C** — можно позже.

## Роли

| Роль | Права |
|---|---|
| Пользователь АДС (диспетчер) | Приём заявок, правка **своих** заявок; видит все заявки, данные квартиры (л/с, ФИО, договор) и дома |
| Начальник АДС | Всё, что пользователь АДС, + правка любой заявки, правка лицевого счёта, ввод оплат, печать, отчёты для ОЭК |
| Главный инженер / начальник антенной службы | Паспорт дома, организация и филиал, схемы СКПТ, ППР, неисправности СКПТ |
| Радиомеханик (Читатель) | Только просмотр дома и схемы, с телефона, без скачивания |
| Юрист | Должники, претензии, пакет в суд, «Дело-Аверс» |
| Бухгалтерия | Отгрузка, оплаты по источникам, сальдо 62.01/62.02, обмен с 1С |
| Администратор | Пользователи, роли, справочники |

## Глоссарий

| Термин | Значение | В коде |
|---|---|---|
| Абонент | Физлицо или юрлицо, у которого есть отводы | `Subscriber` |
| Отвод | Подключение к домовой антенной сети, единица начисления | `Connection` |
| Лицевой счёт | Номер счёта абонента в старой системе | `AccountNumber` |
| Внутренний код | Внутренний идентификатор записи абонента | `LegacyInternalCode` |
| ПЖРЭУ / ПЖРУ | Жилищное ремонтно-эксплуатационное управление; индекс и счёт ПЖРЭУ у дома | `HousingOfficeIndex` |
| СКПТ | Система коллективного приёма телевидения | `AntennaSystem` |
| ППР | Планово-предупредительный ремонт | `PlannedMaintenance` |
| Заявка | Обращение жильца о неисправности | `Demand` |
| ОЭК | Платёжный агент, принимает платежи от населения (расшифровку уточнить, вероятно Омская энергосбытовая компания) | `PaymentAgent` |
| ТСЖ / ТСН | Товарищество собственников жилья; платит за физлиц по счетам | `Hoa` |
| Организация / филиал | Обслуживающая дом организация (не «УК») | `ServiceOrganization`, `Branch` |
| N_OS, N_KASS, N_OPER, N_КВИТ | Номера отделения, кассы, операции, квитанции в единой квитанции | `ReceiptRefs` |
| Дело-Аверс | Учёт судебных дел (что это — Q-04) | — |
