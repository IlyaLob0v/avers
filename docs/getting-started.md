# Запуск для знакомства и обучения

Здесь описано, как запустить «Аверс» на своём компьютере с учебной базой: вымышленные абоненты, дома и заявки.
Настоящие данные не нужны и не затрагиваются. Установка в офисе для работы описана в [09-server.md](09-server.md).

Есть два способа:

- **Только программа на компьютере.** Самый простой, его хватает, чтобы посмотреть все разделы.
- **Сервер на компьютере, программа и телефон.** Нужен, чтобы проверить страницу радиомеханика на телефоне
  и работу нескольких программ с общей базой.

## Подготовка

1. Установите **.NET 10 SDK**: откройте https://dotnet.microsoft.com/download/dotnet/10.0, в колонке «SDK 10.0…»
   выберите **Windows x64**, запустите скачанный файл и пройдите установку до конца. Если .NET не установлен,
   файлы запуска сами об этом скажут.
2. Получите копию репозитория: `git clone https://github.com/IlyaLob0v/avers.git` или на странице репозитория
   **Code → Download ZIP** и распакуйте архив. Если копия уже есть, обновите её командой `git pull`.

## Способ 1. Только программа

1. Откройте папку репозитория в Проводнике.
2. Дважды щёлкните **«Запустить Аверс.bat»** (в Linux — `Запустить Аверс.sh`). Первый запуск собирает
   программу, это занимает одну-три минуты. Чёрное окно не закрывайте.
3. В окне входа выберите учебного пользователя из списка, пароль у всех `avers`.
4. Чтобы войти под другим сотрудником: меню **«Файл → Сменить пользователя»**.

У программы в этом режиме своя учебная база на компьютере. Рабочая дата в ней 31.08.2026, поэтому долги
и «жёлтые» квартиры считаются на эту дату. Список учебных пользователей — в
[руководстве пользователя](user-guide/README.md#учебный-режим).

## Способ 2. Сервер, программа и телефон

Компьютер становится небольшим сервером «Аверса», как в офисе, а телефон открывает страницу механика через
Wi-Fi. Компьютер и телефон должны быть в **одной сети Wi-Fi** (или компьютер подключён кабелем к тому же роутеру).
Через мобильный интернет телефон сервер не увидит.

### Шаг 1. Запустите сервер

1. Дважды щёлкните **«Запустить сервер Аверса.bat»**.
2. Откроется второе окно **«Сервер Аверса»**. Не закрывайте его, пока проверяете: закрытое окно останавливает
   сервер.
3. Windows спросит про брандмауэр. Отметьте **«Частные сети»** и нажмите **«Разрешить доступ»**, иначе телефон
   не подключится.
4. В первом окне появится адрес для телефона, например `http://192.168.1.35:5115/m/`. Если адресов несколько,
   берите тот, что начинается с `192.168.`.
5. Затем откроется программа, подключённая к этому серверу. Здесь логин вводится вручную, например `admin`,
   пароль `avers`.

### Шаг 2. Откройте страницу на телефоне

1. В браузере телефона наберите адрес из шага 1 полностью, вместе с `http://`. Адрес с `https` здесь
   не откроется.
2. Логин `novikov`, пароль `avers`.
3. Выберите улицу и дом: откроется карточка дома со схемами СКПТ.

### Шаг 3. Проверьте связку компьютер — телефон

1. В программе войдите как `engineer` / `avers`.
2. **«Дома»** → дом → **«Схема СКПТ»** → **«Добавить схему»** → любая картинка JPG или PNG до 10 МБ.
3. Обновите страницу этого дома на телефоне: схема появится сразу.

### Запуск сервера вручную

```bat
dotnet run --project src\Avers.Server\Avers.Server.csproj --urls http://0.0.0.0:5115
```

Дождитесь строки `Now listening on: http://0.0.0.0:5115`. Адрес компьютера покажет команда `ipconfig`
(строка «IPv4-адрес»), адрес для телефона — `http://<этот адрес>:5115/m/`.

### Как остановить

Закройте окно «Сервер Аверса» и программу. Учебная база сервера хранится в файле `avers-server-demo.db`
в папке репозитория. Чтобы начать с чистыми учебными данными, удалите этот файл при выключенном сервере:
при следующем запуске он создастся заново.

## Если не получается

| Что видно | Что сделать |
|---|---|
| «Не найдена платформа .NET 10» | Установите .NET 10 SDK, закройте окно и снова запустите файл |
| Телефон пишет «Не удаётся открыть страницу» | Проверьте, что окно «Сервер Аверса» открыто и телефон в той же сети Wi-Fi. Если доступ в брандмауэре не разрешили: **Брандмауэр Защитника Windows → Разрешение взаимодействия с приложением → Изменить параметры**, найдите `dotnet` и отметьте «Частные» |
| Всё равно не открывается | Сеть может быть отмечена как общедоступная: **Параметры → Сеть и Интернет → Wi-Fi → ваша сеть → Тип профиля сети: Частная** |
| «Сервер не ответил за 3 минуты» | Прочитайте последние строки в окне «Сервер Аверса», там причина ошибки |
| Неверный логин или пароль | Пароль учебных пользователей `avers`, логин латиницей маленькими буквами. После многих неудачных попыток подождите минуту |
